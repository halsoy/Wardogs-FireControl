# Changelog

## 1.0.0 — 2026-09-21

- Added external desktop coordinate capture with local OCR.
- Added configurable global target and gun hotkeys.
- Added L81 Mortar and SPH-2 flat-table firing solutions.
- Added six named gun positions and twenty named targets per map.
- Added simultaneous firing solutions for every saved gun.
- Added permanent, selectable tower firing data.
- Added per-target removal and confirmed bulk removal.
- Added persistent local state and manual coordinate entry.
- Added dark Windows UI and clearer gridded data tables.
- Locked the interface to its tested size so controls cannot overlap or leave the window.
- Added the bullseye application icon to both release formats.
- Expanded capture bindings from function keys to arbitrary keyboard keys and modifier combinations.
- Redesigned the hotkey dialog to match the dark interface and remain above an always-on-top main window.
- Redesigned the manual target and gun dialogs as owned dark modals that remain above the main window.
- Expanded the fixed tower table to show every row without a scrollbar.
